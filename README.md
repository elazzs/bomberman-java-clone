# Bomber Man Clone (Java)

This repository contains a playable clone of the classic Bomber Man game. It was developed as a hands-on educational project to build a strong foundation in Object-Oriented Programming (OOP) and software design using Java.

## Project Purpose & Status
This project successfully served its purpose as a learning tool and is currently **archived** (no further updates are planned). It stands as a practical application of core software engineering principles.

## Technologies and Concepts Applied
* **Language:** Java
* **Core Concepts:** Object-Oriented Programming (OOP), Game Loop mechanics, Collision Detection, and Event Handling.
* **Structure:** Multi-class architecture separating logic, assets, and user interface.
